# 柴犬陣取りゲーム (Shiba Jintori)

柴犬を操作して電柱におしっこをひっかけ、3本の電柱で囲んだ三角形をなわばりにする陣取りゲームです。
.NET 10 + SDL3 (SDL3-CS) で動きます。画像・音声ファイルは使わず、ドット絵も効果音もBGMもすべてコード内で生成しています。

## ビルドと実行

.NET 10 SDK が必要です。SDL3 本体は NuGet パッケージ (SDL3-CS.Windows / SDL3-CS.Linux / SDL3-CS.MacOS) から自動で入ります。

```
dotnet run -c Release
```

配布用の実行ファイルを作る場合 (RID は win-x64 / linux-x64 / linux-arm64 / osx-arm64 など):

```
dotnet publish -c Release -r win-x64 --self-contained
dotnet publish -c Release -r linux-x64 --self-contained
```

## 配布パッケージの作り方

アイコンは `packaging/icons` にあります (Windows用 `.ico` と、Linux用の 16〜256 ドットの PNG)。

**Windows (Inno Setup 7 64bit版が必要)**

```
powershell -ExecutionPolicy Bypass -File packaging\windows\build-windows.ps1
```

`dist\ShibaJintori-<バージョン>-win-x64-setup.exe` ができます。インストール時に「自分だけ」か「すべてのユーザー」かを選べます。

**Linux (.deb)**

```
bash packaging/linux/build-deb.sh          # x64
bash packaging/linux/build-deb.sh arm64    # arm64
sudo apt install ./dist/shibajintori_<バージョン>_amd64.deb
```

本体は `/opt/ShibaJintori` に入り、`/usr/bin/shibajintori` (起動用スクリプト)、
`/usr/share/applications/shibajintori.desktop`、`/usr/share/icons/hicolor/` 以下のアイコンが置かれます。
パッケージのメンテナ名は環境変数 `MAINTAINER="名前 <メール>"` で指定できます。

バージョン番号は `ShibaJintori.csproj` の `<Version>` を変えると、インストーラと deb の両方に反映されます。

`dotnet run -- --selftest` で、画面を出さずにAI同士を対戦させてルールの動作確認ができます。

## 操作

| キー | 動作 |
|---|---|
| 矢印キー / WASD | 移動 (1マスずつ) |
| スペース / Z / X | 隣の電柱におしっこ (3秒間動けない) |
| P | ポーズ |
| M | BGM のオン/オフ |
| F11 | フルスクリーン切り替え |
| Esc | タイトルへ戻る / 終了 |

ゲームパッドにも対応しています (起動後につないでも認識します)。

| パッド | 動作 |
|---|---|
| 左スティック / 十字キー | 移動 |
| A / B / X / Y | おしっこ、決定 |
| START | 決定、プレイ中はポーズ |
| BACK (SELECT) | タイトルへ戻る / 終了 |

プレイ中にパッドの接続が切れた場合は自動でポーズします。

タイトル画面では左右キーで柴犬の色 (茶・黒・白) を選べます。しばらく放置するとハイスコア表示 → デモ画面に進みます。

## ルール

- 電柱 3 本におしっこをひっかけると、その三角形の内側が自分のなわばりになる (色が変わる)。面積 1 マスにつき 10 点。
- まだなわばりになっていない電柱は、他の犬の印を上書きできる。上書きされた犬はその電柱をやり直し。
- なわばりになった電柱 (色帯つき) はのっとれないが、新しいなわばりの起点には使える。
- 印をつけた電柱が、ほかの犬のなわばりに取り込まれると、その印は解除される。
- 三角形の内側に他の犬のなわばりが少しでもあると、なわばりは成立しない (辺や電柱で接するだけなら可)。
  3本目のおしっこ中、成立しない三角形は予告線が赤く点滅する。成立しなかった場合は「NO GOOD」と表示され、印は全部取り消されて最初からやり直し。
- なわばりが完成したとき中にいた他の犬は退場 (自分が敵を囲めば +500 点)。
- 自分が敵のなわばりに囲まれる、または車にひかれると残機が減り、なわばり外のどこかに復活する。残機 0 でゲームオーバー。
- 自分以外のなわばりには入れない。
- フィールドの 3/4 がなわばりになるか、制限時間 (240 秒) が切れるとステージ終了。
  自分の面積が敵のどれか 1 匹より小さければ失敗で、同じステージをやり直し。
- 敵はステージ 1 で 1 匹、ステージごとに 1 匹増えて最大 8 匹。ステージ 4 から道路が 2 本になる。

## 追加要素

- **アイテム (ステージ5から)**: なわばりの外に現れ、12秒で消える (消える前に点滅)。敵も踏めば拾う。
  - 骨: 12秒間、おしっこの時間が半分になる。
  - 忍者の巻物: 10秒間、ほかの犬のなわばりを通り抜けられる (犬が半透明になる)。効果が切れたときに他のなわばりの中にいると、外のどこかへ放り出される (残機は減らない)。
- **雨 (ステージ8から)**: 「RAIN IS COMING!」の予告が5秒出たあと降りだし、その瞬間に、まだなわばりになっていない印が全部流れる。なわばりは残る。
- **ボス犬 (8の倍数のステージ)**: セントバーナード。歩くのもおしっこ (5秒) も遅いが、ほかの犬のなわばりを自由に歩き、
  三角形の中にあるほかの犬のなわばりごと奪い取る。ボスを囲んで退場させると +3000 点。

- **夜のボーナスステージ (4の倍数のステージをクリアした直後。ステージ番号なし)**: 犬たちは眠っていて、動けるのは柴犬だけ。
  60秒間、残機は減らない。なわばりは 1 マス 30 点、眠っている犬を囲むと +2000、全員囲むと PERFECT で +5000。
  ただし 2 マス以内に近づくか、3 マス以内でおしっこをすると犬が目を覚まして逃げる (起きた犬を囲むと +1000。離れるとまた眠る)。
  見えるのは柴犬の周り・印をつけた電柱の周り・自分のなわばりだけ。眠っている犬は「zZ」、起きた犬は光る目で分かる。

出はじめるステージは `World.cs` 冒頭の `ItemFromStage` / `RainFromStage` / `BossEvery` で変えられます。
テストプレイ用に `dotnet run -c Release -- --stage 8` で途中のステージから、`-- --bonus` でボーナスステージから始められます。

## 敵の犬種の性格

| 犬種 | 性格 |
|---|---|
| コーギー (STEADY) | 足が短くて少し遅いが、用心深く堅実 |
| チワワ (QUICK) | すばしこいがスタミナがなく、ときどき休む。小さななわばりを作りがち |
| シェルティー (HERDER) | 牧羊犬。ほかの犬を囲い込もうとする |
| ハスキー (FIERCE) | 攻撃的。柴犬の近くに陣取り、大きななわばりで囲みに来る。車には無頓着 |
| パグ (LAZY) | のんびり屋。歩くのが遅く、すぐ昼寝する |
| ダルメシアン (RUNNER) | 足が速く遠くの電柱まで走る。道路をあまり気にしない |
| プードル (CLEVER) | 迷いがなく、ほかの犬の印をどんどん上書きする |
| ビーグル (NOSY) | においに夢中。ほかの犬の印に引き寄せられ、気まぐれに寄り道する |

数値は `Breeds.cs` の `Temper` にまとめてあり、そこを変えると調整できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `SpriteData.cs` | ドット絵の原画 (文字で描いた 16x16 の絵) |
| `Breeds.cs` | 犬種ごとの配色・耳の形・なわばりの色・性格 |
| `World.cs` | ゲームのルール、敵AI、車 (SDLに依存しない) |
| `App.cs` | 画面遷移と描画 |
| `Gfx.cs` | SDL3 描画ラッパー、スプライト生成、キー入力 |
| `Audio.cs` | 効果音とBGMの合成 |
| `HiScores.cs` | ハイスコア上位 10 件の保存 |

ハイスコアは Windows では `%APPDATA%\ShibaJintori\hiscores.txt`、Linux では `~/.config/ShibaJintori/hiscores.txt` に保存されます。
