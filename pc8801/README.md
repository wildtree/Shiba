# 柴犬陣取り — PC-8801mkIISR (V2モード) 移植版

もとの .NET 10 + SDL3 版 (`../README.md`) を、PC-8801mkIISR の V2 モードで動く
Z80 の機械語に移植したものです。BASIC は使いません。電源を入れると
ディスクから直接起動します。

```
pc8801/
  SHIBA88.D88        ← できあがり (起動可能な 2D ディスクイメージ)
  src/               Z80 アセンブラのソース
  tools/             自作のアセンブラ・エミュレータ・ビルドスクリプト
  emulator/          QUASI88 と ROM (このリポジトリには同梱していません)
```

---

## 動かし方

### QUASI88 の場合

1. `emulator/QUASI88.exe` を起動する
2. **V2 モード**・**4MHz** にする (同梱の `QUASI88.ini` は最初からその設定です)
3. ドライブ 1 に `SHIBA88.D88` を入れる
4. リセットする

ディップスイッチは「ディスクから起動する」(SW2-7 = ON) にしておいてください。

### 実機の場合

2D (320KB) のディスクに書き戻して、ドライブ 1 に入れて電源を入れます。
本体の BASIC モードのスイッチは **N88 V2** にしてください。

## 操作

| キー | 動作 |
|---|---|
| テンキー 2 4 6 8 / 矢印キー / WASD | 移動 (1マスずつ) |
| スペース / Z / X | 隣の電柱におしっこ (3秒間動けない) |
| P | ポーズ |
| R (ポーズ中) | ギブアップ (そのステージを最初からやり直す) |
| M | BGM のオン/オフ |
| ESC | タイトルへ戻る |

ジョイスティック (SR 以降の I/O ポート) にも対応しています。
SSG の I/O ポート A/B を入力にして読んでいるので、方向はそのまま、
トリガ 1/2 がおしっこになります。

タイトル画面では左右 (テンキー 4 6 / 矢印) で柴犬の色 (茶・黒・白) を選べます。
上 (テンキー 8 / ↑) でハイスコア表、下 (テンキー 2 / ↓) で実績の一覧です。
15 秒ほど放置すると、ハイスコア表を 8 秒見せてからデモが始まります (元の版と同じ)。

### ハイスコアと実績 (`src/records.asm`)

元の版と同じく、**ハイスコアは上位 10 件** (イニシャル 3 文字・点・ステージ)、
**実績は 24 個**です。

- ゲームオーバーで表に入る点なら名前入力になります。上下 (テンキー 8 2 / 矢印) で
  文字を選ぶか、英字・数字のキーをそのまま打ちます。左右で移動、RETURN / スペースで決定。
- 実績を取ると、HUD の下にアイコンと名前が 4 秒出ます (たまっていれば順に)。
- 実績の一覧は 8 列 x 3 行。取ったものはアイコン、まだのものは「?」。
  選ぶと名前と条件が出ます (まだのものは元の版と同じく伏せてあります)。
- デモ画面では実績は取れません。
- アイコンは元の版の 16x16 の絵 (`SpriteData.cs`) を横 2 倍・縦 1 倍の 32x16 に
  したもの。`tools/icons.py` が色ごとの 1 ビットの絵にして、約 3KB に収めています。
  元の版の取得日時は持っていません。

## 画面の作り

- **640x200 ドット / 8 色** (V2 のアナログパレットで 512 色中 8 色)
- **1 マス = 16x8 ドット**。フィールドは 30x25 マス = 480x200 ドット。
  右の 160 ドット (x=480〜639) が HUD です。
  640x200 のドットは縦長 (およそ 2:1) なので、16x8 のマスは
  ブラウン管の上ではほぼ正方形に見えます。
- テキスト画面は消して (ポート 53h)、GVRAM だけで描いています。
  文字も自前の 8x8 フォントを GVRAM に描いています。
- GVRAM は独立アクセスモード (ポート 5Ch/5Dh/5Eh) を使っています。
- **HUD は元の版の DrawPanel と同じ並び** (暗い紺色、見出しは水色、値は白)。
  上から 肉球の「SHIBA JINTORI」/ STAGE 01 / SCORE・HI (7 桁) / LIVES (柴犬の顔、
  6 匹以上は「顔 x 数」) / TIME / AREA nn%/75% と犬ごとの色を並べた帯 (75% に白い目印) /
  犬ごとの色の印・顔・名前・面積 (自分は黄色、囲まれた犬は OUT)。
  元の版の文字は 400 ドットの画面で 8 ドット = こちらの 4 行ぶんなので、
  8 行の文字が重ならないよう行の間だけ少し詰めています。犬ごとの性格の一言は入りきらないので省略。
  一番下に実績の通知とメッセージ (OUCH! など) の行があります。
  `DRAWCHAR` は HUD の列に描くときだけ背景を色 1 にするので、
  HUD の文字はどこから描いても背景がそろいます。
- フォントは大文字・数字・記号に加えて**小文字と (C) マーク** (0x7F) があります。
- 残機の顔は元の版の正面の頭 (16x10) から 8 行を取った絵です。黒柴は体も輪郭も
  HUD の紺と同じ色になって消えてしまうので、水色の輪郭・黄色のまゆの絵を使います。

### タイトル画面 (`src/title.asm`)

元の版の `App.DrawTitle` の並びを、640x400 → 640x200 に縦半分で写しています。

- 背景は草を暗くしたもの (タイトルのあいだだけ色 0 と 5 を暗い緑にする)
- 肉球の飾り / ハイスコア
- 大きな「SHIBA JINTORI」。元の版はフォントを 5 倍にしているので、
  `tools/art.py` が横 5 倍・縦 2.5 倍に描いて、影と字の 2 枚の 1 ビット絵にしている
- 柴犬えらび (選んでいる柴犬は黄色い枠で跳ねる) / 点滅する開始の案内。
  柴犬は元の版と同じ正面の絵 (`SpriteData.cs` の頭 10 行 + 胴 6 行) を
  横 3 倍・縦 1.5 倍にした 48x24。舌の赤と、黒柴のまゆ・足先の茶色は
  あとから重ねて描く (重ねる色のない 16x8 の枚は飛ばす)
- 遊び方 / 行進する犬たち (選んだ柴犬が先頭) / 下の帯に著作権表示

文字は元の版と同じく 1 ドットの影つきで、背景の草を残して重ね書きします。
点滅は「描いた絵を取っておいて戻す / 草で塗りなおす」なので 1 フレーム未満です。
元の版の「UP: HIGH SCORES / DOWN: ACHIEVEMENTS」は、この移植に
その画面がないので、柴犬えらびの案内に置きかえています。

### 色の割り当て

色番号はプレーンのビットそのものです (bit0 = 青プレーン, bit1 = 赤, bit2 = 緑)。
スプライトの輪郭はプレーン 0 だけ、白は 3 プレーン全部になるので、
1 番を輪郭色、7 番を白に固定してあります。

| 番号 | RGB (各 0〜7) | 使い道 |
|---|---|---|
| 0 | 2,5,1 | 草 (GVRAM が 0 のところ) |
| 1 | 1,1,2 | 輪郭・アスファルト |
| 2 | 7,1,1 | 赤 |
| 3 | 7,4,0 | 橙 (柴犬) |
| 4 | 2,5,7 | 青 |
| 5 | 1,3,1 | 濃い草 (地面の模様) |
| 6 | 7,7,2 | 黄 |
| 7 | 7,7,7 | 白 |

8 色しかないので、なわばりは **単色と市松模様の組み合わせ** で
10 種類を描き分けています (例: 赤+白の市松 = ピンク、白+黒の市松 = 灰)。
さらに、**持ち主の違うマスと接する辺には輪郭色で縁をつけます**。
もとの版の「なわばりの縁取り」と同じ見え方になります。

地面は 4 種類の模様を市松に敷いて、草むらに見えるようにしてあります。
雨の間は地面の色 (パレット 0 番) を暗い青に変えています。

## 速さの作り方

4MHz の Z80 でフィールド 750 マスを毎フレーム描くのは無理なので、
次のようにしています。

- **ゲームの進行は 30Hz** (垂直帰線 2 回で 1 ティック)。
  時間の定数はすべてティック単位 (`TICKHZ = 30`)。
- **背景は汚れたマスだけ描き直す。** 汚れたマスは待ち行列で持っていて、
  毎ティック 800 マスを走査することはしません。
- **スプライトは、その下のマスだけを次のティックで汚す。**
  16x8 のスプライトがマスにぴったり載っているときは 1 マス、
  ずれているときだけ 2〜4 マスを汚します。
- **マスの塗りは 8 行をアンロール**して、1 プレーンあたり 250 サイクルほど。
- **スプライトのプレーン分解は絵のほうに入れてある。**
  1 バイト列 (8 ドット) あたり 4 バイト — マスク / プレーン 0 の下地 (輪郭と白) /
  プレーン 1,2 の下地 (白) / 体 — を `tools/art.py` が吐くので、描くときは
  「読む → AND → OR → 書く」だけ。16 バイト列ぶんを全部展開してあります。
  これで 16x8 のスプライト 1 枚が 10,500 → 約 4,000 サイクルになりました。
- **車と道路は透明なしの絵として `LDI` で流し込む。**
  車は道路の上しか走らないので、背景にアスファルトを焼きこんで
  32x8 を丸ごと不透明にしてあります。車 1 台が 21,000 → 約 2,900 サイクル。
  道路のマスも同じ方式で 10,500 → 約 1,500 サイクル。
- **動いていない車の下は描き直さない。** `CARSMARK` が `FLUSHDIRTY` の前に走り、
  車が前の場所を離れたときだけそのマスを汚します。
- **垂直帰線は数える。** 重いループのあちこちで `VBPOLL` が帰線の立ち上がりを
  数えているので、処理が 1 フレームを超えても「待ちきれなかったぶん」を
  もう一度待つことがありません (2.7 フレームの処理が 3.9 フレームになっていた)。
- **1 ティックにやる量に上限をつけてある。**
  描き直すマスは 64 マスまで (`FLUSHBUDGET`)、考え直す敵は 1 匹まで
  (`AIBUDGET`)。大きななわばりを取った瞬間に固まらないようにするためです。
- **敵の道さがしは帰線を待つ時間にやる** (`src/path.asm`)。
  元の版と同じ幅優先探索 (犬の位置から全マスへの歩数) ですが、1 回に
  数万サイクルかかるので、メインループの最後で「本来なら帰線を待って
  遊んでいる時間」だけ少しずつ進めます。帰線をそこで見つけたら
  `WAITVSYNC` はもう待ちません。だから探索のせいでゲームは遅くなりません。
  探索は 1 度に 1 匹ぶんで、ふつう 10 ティックほどで終わります。
  犬はおしっこが終わる少し前に頼んでおくので、待たずに歩きだせます。
  探索の結果から「行ける電柱」だけを選び、道順を覚えて歩き、
  ふさがったら探しなおします。
- **AI の下見は広すぎる三角形を概算で済ませる** (`EVALQUICK`)。
  実際になわばりを取るときの判定は常に正確に数えます。

自作エミュレータで測った実測値 (`python tools/speed.py`):

| ステージ | 敵の数 | 1 ティック | 実際の速さ |
|---|---|---|---|
| 1 | 2 | 2.03 フレーム | 29.6 Hz |
| 2 | 3 | 2.02 フレーム | 29.7 Hz |
| 4 | 5 | 2.27 フレーム | 26.5 Hz |
| 6 | 7 | 3.26 フレーム | 18.4 Hz |
| 8 | 9 | 3.97 フレーム | 15.1 Hz |

(4MHz の値です。8MHz モードならだいたい半分の重さになります。)

敵が増えるほど重くなりますが、これは犬 1 匹につきスプライト 1 枚と
その下の 2〜3 マスを毎ティック描き直すぶんで、そのまま効いてきます。
ステージ 4 からは道路が 2 本・車線が 4 本になり、元の版と同じく
右向きと左向きの車が走るので、車のぶん (1 ティックに 2 万サイクルほど) 重くなります。

## 音

YM2203 (OPN) をポート 44h/45h で鳴らしています。

- **BGM は FM 3 声** (チャンネル 0 = 主旋律 / 1 = 裏拍の和音 / 2 = ベース)。
  曲は元の版 (`Audio.RenderTune`) と同じ 16 小節の 1 曲で、元の版と同じく
  タイトルと夜のボーナスは「ゆっくり (1 ステップ 6 ティック)・やわらかい音色」、
  ステージとボスは「速め (5 ティック)・明るい音色」で鳴らします
  (元の版は 0.21 秒 / 0.16 秒、三角波 / 矩形波)。
  ステージクリア・ステージ失敗・ゲームオーバーのジングルも元の版の音です。
- 曲とジングルと効果音のデータは `tools/sfxgen.py` が元の版の音の指定から作ります。
  直したら `python tools/sfxgen.py --write` で `src/sound.asm` の自動生成の区間を
  書き換えてからビルドします。
- **効果音は SSG のチャンネル A**。優先度つきで 15 種類。
  FM と別のチャンネルなので、効果音で BGM が途切れません。
- SSG の I/O ポートはジョイスティック用に入力のままにしてあります。
- **音はゲームのループとは別に進む。** `VBPOLL` が帰線 2 回ごとに `SNDTICK` を呼ぶので、
  画面を描き換えているあいだ (`CLS`・文字・HUD・ステージ作り) やディスクを待つあいだ、
  処理が重いティックでも曲の速さが変わりません。長いループには `VBPOLL` を入れてあります。
  ただし GVRAM を C000h に出している最中は音源をさわらず、いったんメイン RAM に戻して
  鳴らしてから、出していたプレーンに戻します (どのプレーンかはポート 5Ch を読んで知る)。
  描画の途中で鳴らすと、書き換えの多い画面で音がブツブツ切れたため。
- 同じ曲がまだ鳴っていれば `BGMSTART` はかけなおさないので、
  タイトルとハイスコア表・実績の一覧を行き来しても曲は続きます。

`tools/sndtest.py` が実際のレジスタ書き込みを拾って音名に直すので、
音色 (4op x 6 項目 x 3 種) の読み込み、和音のキーオン、効果音の
周期・音量・ミキサ操作を目で確かめられます。

音階は F-Number の表 (1 オクターブ分) とブロックで作っています。
クロック 3.9936MHz のとき `f = fnum * 3993600 / (72 * 2^(21-block))`。

## メモリの使い方 (64K RAM モード)

```
0000-00FF  未使用
0100-47xx  コードとデータ
9000-AB00  配列 (なわばり / 電柱 / 汚れ / 三角形の内外 / 待ち行列)
AB00-AE5F  道さがしの歩数 (32x27、上下 1 行は番兵の壁)
AF40-B4DF  犬・電柱・車・アイテム・道順 (ROUTES)
B500-B6xx  スカラ変数
B700-B7FF  ディスクのセクタ 1 個分
B800-B9FF  道さがしの待ち行列 (下位バイト / 上位バイトで 1 ページずつ)
BC00-BCFF  起動時のローダ (起動後は未使用)
BD00-BFFF  スタック
C000-FFFF  GVRAM の窓
```

配列は 1 行 32 バイト間隔なので、`添字 = y*32 + x` がシフトだけで出せます。

## 起動のしくみ

PC-8801 の N88-BASIC ROM は、ディスクから起動するとき
**ドライブ 1 / トラック 0 / セクタ 1 の 256 バイトを C000h に読み込んで実行** します。
そこに置いた 256 バイトが `src/boot.asm` です。やっていることは:

1. 割り込みを止めて 64K RAM モードにする
2. ディスクサブシステム (8255 のハンドシェイク、ポート FCh〜FFh) に
   `02h` Read Data と `03h` Send Data を発行して、本体を 0100h 以降に読み込む
3. 0100h へジャンプ

ハイスコア表と実績は **論理トラック 78 / セクタ 1** の 1 セクタに書いています
(書き込み禁止のディスクでも落ちないようにしてあります)。

| 位置 | 中身 |
|---|---|
| +0 | 目印 `8Bh` (前の版の `8Ah` = 1 位の点だけ、も読める) |
| +1〜+80 | ハイスコア 10 件 x 8 バイト (点 3 / 名前 3 / ステージ 1 / 予備 1) |
| +81〜+83 | 実績 24 個のビット |
| +84 | 途中経過 (3 色の柴犬それぞれでクリアしたか) |

ゲーム中にディスクを回すと止まって見えるので、実績はその場では書かず、
ステージの切れ目とゲームオーバーのあとにまとめて書きます。

## 作り方

Python 3.8 以降だけあれば作れます。外部ライブラリは要りません。

```bash
python tools/build.py
```

`SHIBA88.D88` ができます。中でやっていることは:

1. `tools/art.py` がドット絵・フォント・模様・パレットを `src/gen_art.asm` に書き出す
2. `tools/z80asm.py` (自作の Z80 アセンブラ) が `src/game.asm` を組む
3. 本体の大きさから `src/gen_size.asm` を作り、`src/boot.asm` を組む
4. `tools/d88.py` が 2D の D88 イメージを組み立てる

### 検査に使うもの

```bash
python tools/test_asm.py                 # アセンブラの符号化テスト
python tools/test_cpu.py                 # Z80 コアのテスト
python tools/artpreview.py prev.png      # ドット絵を一覧にして確認
python tools/prof.py --stage 8 --ticks 20 --warm 900  # 処理時間をルーチン別に
python tools/speed.py                    # ステージごとの実際の速さ
python tools/aitest.py --stage 4 --secs 60  # 敵 AI がなわばりを作れるか
python tools/sndtest.py                  # OPN への書き込みから BGM と効果音を確認
python tools/featuretest.py              # アイテム / 雨 / ボス犬 / 夜の面
python tools/play.py --script "wait 320; key space 4; wait 400; shot s.png"
python tools/bot.py --frames 4000        # キーを押して柴犬を動かす
```

`tools/pc88emu.py` は、この移植のために書いた PC-8801 のエミュレータです。
**実機の ROM (`emulator/ROM/n88.rom` など) をそのまま読み込んで起動する** ので、
ディスクからの起動は本物の N88-BASIC ROM の IPL を通っています。
ディスクサブシステムは 8255 のハンドシェイクのレベルで模擬しています。

## もとの版との違い

Z80 と 640x200 に合わせて変えたところです。ルールは変えていません。

| | もとの版 | PC-8801 版 |
|---|---|---|
| 1 マス | 16x16 ドット | 16x8 ドット (ブラウン管上はほぼ正方形) |
| 進行 | 60fps | 30fps (垂直帰線 2 回で 1 ティック) |
| 色 | フルカラー | 8 色 + 市松模様 + 縁取り |
| 犬の絵 | 犬種ごとに 16x16 の原画 | 耳 3 種 (立ち/大きい/たれ) x 4 方向 x 2 コマ + おしっこの絵、色で区別 |
| ボス犬 | 2 倍の大きさ | 32x16 ドット (16x8 を 4 枚) |
| 浮かぶ文字 | フィールド上に出る | HUD の下に出る |
| 三角形の予告線 | 点線で結ぶ | 印をつけた電柱が点滅する枠で分かる |
| 敵の経路 | 毎歩 BFS | 目標を決めるときに 1 回だけ BFS (帰線待ちの時間に少しずつ)。道順を覚えて歩き、ふさがったら探しなおす |
| 3 本目の電柱 | 候補ごとに Evaluate | 外接箱の大きさで見積もり、best だけ Evaluate で確認 |
| 歩数の目安 | BFS の距離 | BFS の距離 (同じ) |
| BGM | 合成波形 | YM2203 の FM 3 声 (曲・テンポは同じ) |
| 効果音 | 合成波形 | YM2203 の SSG 1 声 |
| ハイスコア | ファイルに 10 件 | ディスクに 10 件 (同じ) |
| 実績 | 24 個 + 取得日時 | 24 個 (日時なし) |
| 実績の通知 | 画面の上にすべり込む | HUD の下に出る |

三角形の内外判定は、3 つの外積の和が面積の 2 倍になる性質
(`d1 + d2 + d3 = 2S`) を使って、バウンディングボックスを 3 回なめるだけに
してあります。外積は x,y の 1 次式なので、足し算だけで隣のマスへ進めます。

## 移植したルール

もとの版の仕様はそのまま入っています。

- 電柱 3 本におしっこ → 三角形の内側がなわばり (1 マス 10 点)
- なわばりになっていない電柱の印は上書きできる
- なわばりに取り込まれた電柱はのっとれない (色帯つき)
- 三角形の内側に他の犬のなわばりがあると成立しない (辺や頂点で接するのは可)
  → 成立しなければ「NO GOOD」で印は全部取り消し
- なわばり完成時に中にいた敵は退場 (+500 点、ボスは +3000 点)
- 敵のなわばりに囲まれる / 車にひかれると残機が減る
- フィールドの 3/4 か、制限時間 240 秒でステージ終了。
  自分の面積が敵のどれかより小さければやり直し
- 敵はステージ 1 で 1 匹、以後 1 匹ずつ増えて最大 8 匹。ステージ 4 から道路が 2 本
- 犬種 8 種の性格 (速さ・用心深さ・スタミナ・好む距離・攻撃性など) は
  `src/data.asm` の `TEMPERTBL` に 16 = 1.0 の固定小数で入っています
- アイテム (ステージ 5 から): 骨 = おしっこが半分の時間、巻物 = なわばりを通り抜け
- 雨 (ステージ 8 から): 5 秒の予告のあと、なわばりになっていない印が全部流れる
- ボス犬 (8 の倍数のステージ): セントバーナード。遅いが、なわばりを踏み越えて奪う
- 夜のボーナスステージ (4 の倍数のステージのあと): 眠っている犬を起こさずに囲む
